# 英単語書き取りドリル

iPad・iPhone で、**日本語の意味を見て英単語のつづりを書く**書き取りドリルです。
[漢字書き取りドリル](https://naitougc8-star.github.io/kanji-drill/)と同じ作り・画面・機能(テストのツリー、成績のグラフ、通常出題とフラッシュ出題、バックアップと QR コード)で、
サーバー処理のない静的サイトです。GitHub Pages にそのまま置けます。

- **取り込み(写真の OCR)**: 単語テスト範囲のプリントを撮影し、表を四角く囲んで「読み取る」を押すと、罫線から 1 マスずつ読み取って
  「番号・英語・日本語」の組を取り出します(①〜⑤ のように、組が横に何組並んでいてもよい)。
  「動詞の過去形の表」を選ぶと、「番号・日本語の意味・原形・過去形」の表を読み、**日本語の意味を見て現在形(原形)と過去形を両方書く**問題にします
  (be 動詞のように、意味のマスが何行かにまたがっていても読めます)。
  - 読み取った結果は確認表で直してから追加します。読み取りに自信がないマスは黄色。
  - 写真が何枚かあるときは 1 枚ずつ読み取ります。前の写真と重なった行(同じ番号)は、確認表で初めから外れています。
  - 斜めから撮った写真(罫線が平行でない)でも、罫線を 1 本ずつ、それぞれの傾きで探して読みます。
  - 写真なしで、「101 walk 歩く」「1 食べる eat ate」の形の貼り付け(表計算ソフトのタブ区切りも)や、1 語ずつの入力もできます。
- **出題**: 日本語の意味を見て、英語を(過去形の問題は「現在形」「過去形」の 2 つの欄に)**キーボードで入力**するか、iPad では **Apple Pencil で入力欄に直接書きます**(iPadOS のスクリブル。
  設定 → Apple Pencil →「スクリブル」をオン)。入力欄は、自動修正・予測変換・自動の大文字・スペルチェックを切ってあります。
- **答え合わせ**: 答えと書いたつづりを 1 字ずつ対応させ(編集距離)、**違った字を赤で**示します(違う字・書き落とした字は _ ・余分な字は取り消し線)。
  - 大文字・小文字は区別しません。前後・続いたスペースは無視します。iPad の「’」は「'」と同じ。
  - 答えの「~」は書かなくてよく、( ) の中は書いても書かなくてもよい。「color / colour」のように / で区切ると、どれでも正解。
  - 過去形の問題は、現在形・過去形をそれぞれ確かめて ○ × を付けます(両方合っていれば正解)。発音は現在形・過去形を 1 語ずつ分けて読み、それぞれの答えの横の 🔊 で、現在形だけ・過去形だけを聞けます。
  - 空白や記号で不正解になったときは「合格にする」で直せます。
- **発音**: 答え合わせのあと(フラッシュ出題では「答え」を押したとき)、端末の音声(英語)で英語を読み上げます。🔊 でもう一度。
  設定で「読み上げる / ゆっくり / 読み上げない」を選べます(iPhone は、消音モードだと鳴らないことがあります)。「3. 出題と画面の設定」に、使う声の名前を出します。
  iPhone・iPad で声が出ないことへの手当てとして、最初に画面を触ったときに音量 0 の読み上げで読み上げを使えるようにし、
  端末に入っている声(プレミアム・拡張を優先)を選び、読み始めなければ声を指定しないで読み直します。
- **成績**: 語ごとに記録し、まだ合格していない語は続けて間違えた回数で 黄・オレンジ・赤、合格した語は緑で「○ 3 回目で合格」。
  「全問」「不合格の語だけ」「3 回以上間違えた語だけ」「未出題の語だけ」を選んで出題できます。出題の順番は「ばらばら / 番号順」。
- **フラッシュ出題**: 日本語を見て英語を思い浮かべ、「答え」で英語を見て(発音を聞いて)「OK! / Maybe OK / もう一回」。
- **バックアップ・ほかの端末と共有**: ファイル(AirDrop・iCloud Drive)か QR コードで。漢字書き取りドリルと同じ仕組みです。

手書きの文字を、このアプリの中で読み取る方式(4 本線のマスに書く)は、あとで足す予定です。

## 漢字書き取りドリルとの関係

同じ `naitougc8-star.github.io` に置くので、ブラウザの保存領域(約 5MB)を分け合います。
保存の名前(`eitango-drill.v1`)とバックアップの種類(`eitango-drill`)は漢字書き取りドリルと別にしてあり、データは混ざりません。

## 構成

```
index.html  style.css  manifest.webmanifest  icons/
app.js       画面の制御(設定 → 出題 → 結果、フラッシュ出題、取り込みの確認表、バックアップ・QR コード)
spell.js     つづりの答え合わせ(比べる形・答えの書き方・1 字ずつの対応)。DOM 非依存
speak.js     英語の読み上げ(Web Speech API、英語の声を選ぶ)
etable.js    表の罫線を探す(線ごとの傾き・太さ)、列の役目、またがったマス、列の画像の切り出し
ocr.js       Tesseract.js で列ごとに読む(番号: 数字だけ、英語: eng と英字だけ、日本語: jpn)
entries.js   読み取ったマスから問題を作る(番号の補い・ごみの除去・重なった行)、貼り付けの読み取り。DOM 非依存
marker.js    写真の上で表を四角く囲む(漢字書き取りドリルと同じ)
sets.js      テスト・写真ごとのまとまり / backup.js バックアップ / qrsync.js QR コード / storage.js 保存
util.js      id・HTML の逃がし・スクリプトの読み込み
vendor/      Tesseract.js(ワーカー・コア・eng / jpn の言語データ)、qrcode-generator、jsQR
scripts/     serve.mjs(開発用サーバー)、copy-vendor.mjs、make-icons.mjs、make-fixtures.mjs
tests/unit   Vitest / tests/e2e Playwright(Chromium と WebKit)
```

ビルド不要です。外部 CDN には依存しません(ライブラリ・言語データはすべて同じオリジンの `vendor/` から読みます)。

## ローカルで動かす(Windows)

Node.js 20 以降が必要です。

```bash
npm install
```

```bash
npm run serve
```

- PC では `http://localhost:8080/` を開きます。同じ LAN の iPad からは、起動時に表示される `LAN: http://192.168.x.x:8080/` を開きます。
- `vendor/` は生成済みのものがリポジトリに入っています。作り直すときは `npm run build:vendor` です。

## テスト

```bash
npm test
```

つづりの答え合わせ・読み上げの声・番号の補い・マスの文字の掃除・貼り付け・罫線の検出(斜めの表、またがったマス)・バックアップ・QR コードの単体テスト(Vitest)です。

```bash
npx playwright install chromium webkit
```

```bash
npm run test:e2e
```

通しテスト(Playwright、Chromium と WebKit、820×1180 のタブレットサイズ、各 7 件):

1. 単語の表のプリント(`tests/fixtures/print-words.png`。2 組 × 8 行、0.8° 傾けてぼかしたもの)を読み取る → 英語 16 語はすべて正しく、日本語は 13 語以上 →
   確認表で直して追加 → 同じ写真をもう一度読むと、もうある行は外れている。コンソールのエラー・失敗した通信・外部への通信が 0 件。
2. 過去形の表(`tests/fixtures/print-past.png`)を読み取る → 原形・過去形 6 語がすべて正しい →「食べる」に eat・ate と書いて正解(読み上げは eat, ate)、go・goed は「過去形がちがいます」で不合格。
3. 入力して答え合わせ: wlak → a・l を赤で示す、i see → 正解(答えは I see と表示)、dont → ' の所に _ →「合格にする」、結果・もう一度・再読み込み後も成績が残る。
4. 読み上げ: 「読み上げない」なら流さず 🔊 では流す、「ゆっくり」は速さ 0.7。
5. フラッシュ出題: 答えで英語と発音、⚡ の記録と「もう一回だけ」。
6. 漢字書き取りドリルの保存データと混ざらない。
7. バックアップ: 書き出したファイルを、保存領域が別のブラウザ(iPhone の大きさ)で読み込んで合わせる。

`scripts/make-fixtures.mjs` で、テスト用のプリントの画像を作り直せます(語はこのプロジェクトで選んだ、よく使う英単語)。
